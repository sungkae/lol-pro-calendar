# LoL 프로 대회 캘린더

LoL Esports 공식 API 기반 프로 대회 일정 캘린더. 리그별 필터, 월별/목록 뷰, 팀 검색.

- 페이지를 열 때마다(그리고 탭 복귀·10분 주기로) 공식 API를 직접 호출해 최신 일정으로 갱신 — 미래 전체 + 과거 45일 백필
- 서버·빌드·저장 데이터 없음. API 장애 시 에러 표시 후 5분 주기 자동 재시도
- 시간은 보는 사람의 기기 시간대로 표시

**커버리지 범위**: lolesports.com이 게시하는 대회 전체 (44개 리그 — 국제전·메이저 리그·2군·ERL 포함).
중국 2군 LDL, 아카데미급 대회는 Riot API에 데이터가 없어 구조적으로 제공 불가.
